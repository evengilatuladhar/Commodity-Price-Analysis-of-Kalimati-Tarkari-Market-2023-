# Commodity Price Analysis of Kalimati Tarkari Market (2023)

## Overview
This project analyzes daily vegetable and commodity prices from Kalimati Tarkari Market using Tableau to identify trends, seasonal patterns, and price fluctuations.

## Tools Used
- Tableau
- Excel / CSV

## Key Insights
- Price variation across different vegetables
- Seasonal trends affecting supply and cost
- Identification of high volatility commodities

## Files
- Tableau packaged workbook (.twbx)
- Dataset
